#Chapter 2
2.1 
What is a CPU?
- A group of components consisting of transistors, that 
execute instructions.

What is the difference between an interpreter and a compiler?
- An interpreter reads each line of code and runs it before 
moving to the next line of code while a compiler first
translates/reads the whole code before running it.

why salesforce have governor limits?
- Governor limits prevent a single transaction of code execution
from using up all the resources on the platform that are shared
 amongst other salesforce users.
